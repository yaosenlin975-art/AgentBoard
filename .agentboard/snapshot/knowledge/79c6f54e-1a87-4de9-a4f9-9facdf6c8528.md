## 结论
任务树每层的 SQL ORDER BY 与 keyset cursor seek predicate 必须使用相同的排序键和顺序。树接口采用 `created_at ASC, id ASC`；游标边界按 `(created_at, id)` 逐字典序推进。

树 cursor v1 保留已发布 payload 的 `sort_order` 字段与类型校验，但该字段不再参与树排序或下一页边界。普通任务列表仍按 `sort_order, created_at, id` 排序。

排序键调整时，SQL ORDER BY、cursor seek predicate 和 cursor 捕获字段需一起核对；只改一处会导致跨页重复、遗漏或次序错误。
