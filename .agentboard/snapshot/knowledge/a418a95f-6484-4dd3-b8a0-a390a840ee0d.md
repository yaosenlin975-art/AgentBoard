# MCP 变更日志工具（MCP-C2：list / show / create）

覆盖卡 `6a2ded57-e4a9-438c-a0f5-ae3d4babbad4`。截至 C2，MCP 主名 38、`tools/list` 总数 76（38 主名 + 38 alias）。

## 1. 工具与端点

| 工具 | 端点 | 入参 | 输出 |
| --- | --- | --- | --- |
| `list_changelog` | `GET /api/workspaces/:workspaceId/changelog` | `workspace_id?`、`limit` 1–100（默认 20）、`offset`、`change_type?`、`q?` | `{ items, next_offset }`，每项正文窗口 300 |
| `get_changelog` | `GET /api/workspaces/:workspaceId/changelog/:id` | `changelog_id`、`body_offset`、`body_max_chars`（默认 12000，上限 20000） | `{ entry }`，正文含 `body_truncated` / `next_offset_chars` |
| `create_changelog` | `POST /api/workspaces/:workspaceId/changelog` | `title`、`body_md`、`change_type`（新增/修复/调整，默认新增）、`occurred_at?`、`request_id` | `{ entry }`（正文窗口 300） |

- 三者都注册 `agentboard_*` alias；写工具需要 `AGENTBOARD_AGENT_ID`（作为 `actor`）。
- 只消费 LOG01 既有 REST，不新增服务端路由。

## 2. 幂等与字段约束

- `request_id` 即 `Idempotency-Key`：**同一 request_id 重复 POST 返回同一条目（同一个 id，不会重复写）**；实测两次相同调用都回 `b0b57a09-…`。
- `change_type` 仅允许 `新增/修复/调整`；`历史` 是导入服务专用，普通写入会 400 `VALIDATION_ERROR`。
- `actor` 由 `AGENTBOARD_AGENT_ID` 填入，服务端同时记 `created_by` / `updated_by`。

## 3. 输出有界

- 列表为了控制体积只回 300 字正文摘要（`body_truncated=true` 时按 `next_offset_chars` 调 `get_changelog` 续读）。
- 详情按 `body_offset` + `body_max_chars` 窗口读，避免长日志（上限 100k 字符）撑爆 40k 工具结果上限。

## 4. 错误码

404 `CHANGELOG_NOT_FOUND`（跨工作区同样 404，防探测）/ `WORKSPACE_NOT_FOUND`；400 `VALIDATION_ERROR`；缺 agent id 本地 `AGENT_ID_REQUIRED`。均走 isError + `structuredContent.error.code`，不回服务端原文。

## 5. 冒烟产物清理

变更日志没有 MCP 删除工具（REST 有 `DELETE /api/workspaces/:workspaceId/changelog/:id`，需 body `{ expected_revision, actor }`）。冒烟条目验证完直接 DELETE 即可，实测 rev:1 删除成功；不做清理会在工作区日志里留下测试条目。
