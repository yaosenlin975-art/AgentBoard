# 壳侧轻量取数：Dock 角标的端点口径与 HTTP 工具（E1）

## 取数口径（后续壳侧集成复用，E2 通知同源）

壳（Rust）直接对本地服务做只读 GET，无需鉴权（本地态接口与 kb CLI 同源）：

- `GET /api/workspaces` → 工作区数组（`id`/`name`）。
- `GET /api/issues?workspace=<id>&fields=status` → **裸数组**（非 `{items}` 包装）`[{status}, …]`；「待验收」在壳侧数（与 `kb stats` 的 readIssues 同一路径）。
- `GET /api/decisions?workspace_id=<id>&state=open&limit=1` → `{decisions, counts:{grace,open,stale_open,answered_recent}}`，**`counts.open` 直接给数**，无需拉全量决策。
- 角标（E1）= 全部工作区的 Σ待验收 + Σcounts.open。对账：单区分量与 `kb stats --workspace <id>` 待验收数一致；总量是多区之和（差异口径）。

## HTTP 工具（server_process.rs `http_get_json`）

std TcpStream 最小 HTTP GET + `Connection: close` 读到 EOF + 按 `\r\n\r\n` 切体 + serde_json 解析；非 200/解析失败返回 None。express `res.json` 恒带 Content-Length（无 chunked），该简单解析安全。

## 轮询与角标语义（main.rs）

- mac-only 线程：成功 30s 一轮；失败（服务未就绪/瞬时错误）5s 退避，**不清角标**；每秒检查 quitting 即时收线。
- `WebviewWindow::set_badge_count(Some(n))`：0/None 均移除角标（归零即消失）；tao 仅 mac 实装（Windows 任务栏对应 overlay icon，非本范围）——调用点 `#[cfg(target_os="macos")]` 门控，取数/解析逻辑全平台编译并配单测（fixture + `#[ignore]` 对 8787 实测对账，`cargo test -- --ignored` 显式跑）。
