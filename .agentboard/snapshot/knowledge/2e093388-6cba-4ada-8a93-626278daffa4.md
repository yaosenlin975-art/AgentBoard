# mac 产物随包 node runtime 与 server payload（B10 三点同步契约）

## 布局契约（三处必须同步改）

mac .app 免装 Node 的链路跨三个文件，改任何一处都要核对其余两处：

1. `scripts/desktop/build-macos.mjs` `stagePayload()`：组装到 `desktop/src-tauri/payload/{runtime/node, app/…}`（app 布局 = Windows 便携包 `<stage>/app` 同构：`apps/server/dist`、`apps/web/dist`、`node_modules/…`）。
2. `desktop/src-tauri/tauri.macos.conf.json`：`bundle.resources=["payload/**/*"]`，tauri build 时复制进 `.app` 与 `.dmg` 的 `Contents/Resources/payload/`（两产物同源；后置塞 .app 会漏 dmg，因为 dmg 由同一次 tauri build 产出）。该文件是 macOS 平台覆盖配置，Windows 构建不合并。
3. `desktop/src-tauri/src/server_process.rs` 的候选：入口 `exe_dir/../Resources/payload/app/apps/server/dist/index.js`；node `exe_dir/../Resources/payload/runtime/node`（名字按平台取：win=node.exe，其它=node，`#[cfg]` 两常量共享同一循环）。

## node 来源口径

- 随包只认 `AGENTBOARD_NODE_DARWIN` 或仓库 `runtime/darwin-<arch>/node`（Mach-O；`.exe` 一律拒绝）。PATH 上的 node 仅构建期兜底、不随包（Homebrew node 可能带外部库依赖，复制不可靠）。
- esbuild bundle 统一 `--target=node20`（README 前置 Node≥20）：构建机 PATH node 与随包 node 版本可能不同，取最低支持档避免新语法打进旧 node。

## tauri bundle.resources 语义（踩坑）

- **map 形式打平目录**：`{"src/**": "dest/"}` 把所有匹配文件直接丢进 dest、不保留子目录结构（官方文档明示），嵌套树会被压扁——不能用它搬 payload。
- **list 形式保留相对路径**：`["payload/**/*"]` 落到 `Contents/Resources/payload/**`，前缀（目录名）保留。想要 Resources 根布局做不到，接受 `payload/` 前缀并把壳的候选对齐即可。
- 平台覆盖配置文件名固定 `tauri.<platform>.conf.json`（如 `tauri.macos.conf.json`），构建对应平台时自动合并。

## 共用组装模块

`scripts/assemble-payload.mjs`（B10 从 package-portable.mjs 抽出）：server/cli esbuild 单文件包、web dist、better-sqlite3/bindings/file-uri-to-path/sherpa-onnx-node + 平台 sherpa 包（win: `sherpa-onnx-win-x64`；mac: `sherpa-onnx-darwin-<arch>`，由 pnpm optionalDependencies 自动装）。`verifyNativeLoad({nodeBinary, appDir})` 用指定 node 加载包内 better-sqlite3 验 ABI，返回 {ok, stderr} 由调用方决定报错文案。

## 顺带修的既有坑

`package-portable.mjs --out <相对路径>` 时包内自检 spawn 相对路径 exe：spawnSync 的 cwd 已切到 appDir，相对命令按新 cwd 解析 → ENOENT、stderr undefined。`--out/--zip` 一律 `resolve()` 成绝对路径。

## 分支合并后的打包与验证口径（MERGE-PULL 79f51696，2026-11-16）

- Windows 便携包组装逻辑唯一落点在 `scripts/assemble-payload.mjs`（B10 委托结构：`scripts/package-portable.mjs` 只 import `assembleAppPayload`/`copyTree`/`logSymlinkStats`/`verifyNativeLoad` 并调用）。后续打包类修复（D3 族：pnpmPackage 依赖链解析回退、better-sqlite3 prebuilds(13.x)/build(12.x) 双候选）只改 assemble-payload.mjs；禁止在 package-portable.mjs 回填内联副本（合并前的远端分支就有内联副本，合并时已删）。
