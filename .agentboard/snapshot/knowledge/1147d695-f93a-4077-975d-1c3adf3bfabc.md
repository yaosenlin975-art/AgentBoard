# PERF-4 /api/issues 收敛契约

## 背景与目标（卡 97a67f45-3f4d-4970-90ee-3a5524696562）
GET /api/issues?workspace_id=… 全量 648 条 1020KB、p50 10.4s；切换面板 WorkspaceCard 每卡各发一次全量（N+1）。目标：字段可裁剪、可分页、计数走轻端点；**缺省行为不变**（不带新参数=现状逐字节同形）。

## 契约（apps/server）
1. `fields=` 白名单：逗号分隔 token，仅裁剪响应字段，id/workspace_id/title/status 恒在（保拖拽与渲染最低需求）；未知 token → 400 中文报错并列可用值；缺省省略 = 完整字段。
2. 分页：`limit=`（正整数，上界 200）+ `offset=`（非负整数，缺省 0）；排序键固定 `(sort_order, created_at)`；二者单独或同用均可；非法值 400。选 offset 不选 cursor：SQLite LIMIT/OFFSET 直接映射，本项目列表无深分页场景。
3. `GET /api/issues/counts?workspace_ids=<id1,id2,…>`：返回 `[{workspace_id, total, counts:{<状态名>:n}}]`，SQL GROUP BY 单查；状态字典含自定义状态；跨工作区聚合一次请求（替代切换面板 N+1）。
4. 回滚开关：`AGENTBOARD_ISSUES_LIST_LEGACY=1` 强制列表走旧全量分支（响应形状不变）；缺省关闭。旧调用（无新参数）行为不变，无需开关即兼容。

## 三端迁移
- web：WorkspaceCard.tsx 改 counts 端点（走 endpoints.ts 注册表，CR-9 产物）；其余 /api/issues 消费方不动（缺省兼容）。
- cli：list-tasks 保持全量（缺省=完整字段不变）；仅在状态计数展示处可选用 counts。
- mcp：issues 工具不动（缺省兼容）；Docs/api.md 记迁移说明。

## 基准方法
改前基线：运行中 8787（旧 dist）curl 三次取样 p50/payload。改后：隔离实例（独立 APPDATA + 拷贝中心库 + 独立端口）同数据集同命令三次取样；验收线 limit=50 p50 ≤500ms、payload ≤100KB。

## 验收对齐卡面 5 条
① p50/payload 双达标（附复算命令与三次结果）；② counts 与全量聚合 3 工作区抽样一致；③ 切换面板零全量请求（浏览器网络记录截图）；④ Docs/api.md 契约+迁移+回滚三节齐全，pnpm -r build 过；⑤ 本设计页即 spec，拍板依据见卡 97a67f45 评论 99157dce。
