# SKILLS-SYNC：把配套技能复制到本机 agent skills 目录

## 目标目录（2026-11-10 本机实测）

固定白名单，接口只收 `target_id`，不接受任意路径：

| id | 路径 | 实测 |
| --- | --- | --- |
| agents | `~/.agents/skills` | 实体目录；其中 7 个技能本身是指向仓库 `skills/` 的 junction |
| claude | `~/.claude/skills` | 父目录存在，可创建 |
| cursor | `~/.cursor/skills-cursor` | junction → `~/.agents/skills`；**不是** `~/.cursor/skills` |
| trae-cn / trae / codex | `~/.trae-cn/skills`、`~/.trae/skills`、`~/.codex/skills` | junction → `~/.agents/skills` |
| qoder / windsurf | `~/.qoder/skills`、`~/.codeium/windsurf/skills` | 实体目录 |
| workspace | `<工作区>/.agentboard/skills` | 传 `workspace_id` 时才枚举 |

## 关键结论与坑

1. **按实体路径去重**：4 个入口指向同一物理目录，探测用 realpath 归并并互相填 `shared_with`，UI 标注「与 X 同一物理目录」，避免重复写同一处。
2. **junction 必须跟随**：`lstatSync().isDirectory()` 对 junction 返回 false，会把存在的目标误判为「不存在」。判定目录一律 `statSync`。
3. **绝不写穿链接**：目标技能目录可能是指向仓库的 junction。覆盖/备份时先只删链接（`unlinkSync`），再落真实复制；否则复制会直接改仓库源码（本次实测把 drift 写进了 `skills/handoff/SKILL.md`）。
4. **移除只删自己写过的**：`<configDir>/skills-sync.json` 的 `written` 记录本工具真实写入的技能名；用户既有的 junction / 手工安装不在名单内，移除时不动。
5. **状态不靠记录猜**：`synced`/`stale`/`never` 由目标实际内容与源清单（文件集合 + 大小 + sha256）逐文件比对得出，源变更后自动变 `stale`。
6. **冲突三选**：未传 `conflict` 且内容不一致 → 409 `SKILLS_SYNC_CONFLICT` + `details.conflicts`；`backup` 备份到 `<目标>/.agentboard-backup-<时间戳>/`。
7. **来源即目标直接拒绝**：解析真实路径相同即报错，绝不先删后拷（会毁掉唯一一份源）。
