# MCP 与 CLI 能力对照：共享纯函数 + 防漂移用例

## 结论

- `next` / `stats` 的筛选、依赖与计数逻辑收敛到 `packages/shared/src/boardViews.ts`，CLI 与 MCP 共用同一份纯函数，天然同形，不存在双实现漂移。
- MCP 侧只负责 REST 取数与入参解析：`next_tasks` 返回 `{ items, next_offset }`，`workspace_stats` 返回 StatsResult，字段名与顺序与 CLI `--json` 一致。
- `workspace-db` / `accounts` / `grep` 等本机系统命令明确不提供 MCP 版：MCP 是远程语义，本机数据迁移与本地文件检索在远程语义下没有意义。

## 防漂移

- `Docs/api.md` §21 维护逐命令对照表（34 个顶层命令），标注 有 / 无 / 永不提供及原因。
- `apps/mcp/test/cliMcpParity.test.ts` 解析 CLI 顶层命令与对照表行，集合不一致即红；新增 CLI 命令必须同步表格才能通过测试。

## 坑

- MCP 侧 `fields=` 裁剪要保留老服务端回落：400 / 404 时退回整对象查询，否则旧服务端直接失败。
- 依赖视图只对候选卡请求，已占用与非「待规划」卡不发请求，避免无谓往返。
