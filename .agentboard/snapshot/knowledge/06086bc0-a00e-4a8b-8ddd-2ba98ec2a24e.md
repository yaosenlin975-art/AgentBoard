# MCP 待决策工具契约（MCP-D1/D2：读取、停止信号、提问、答复、宽限、撤回）

覆盖卡 `64acde61-a358-44c4-8bf0-10a3776363b6`（读取/提问）与 `d6753e4c-aab2-4b1a-9a0f-46dff13a8d0b`（答复/宽限/撤回）落地的 7 个 MCP 工具。D2 之后 MCP 主名 32、`tools/list` 总数 64（32 主名 + 32 `agentboard_*` alias）。

## 1. 工具与端点映射

| 工具 | 读/写 | 端点 | 关键入参 |
| --- | --- | --- | --- |
| `list_decisions` | read | `GET /api/decisions` | `workspace_id`（未绑定必填）、`issue_id`、`state=grace\|open\|answered\|withdrawn`、`stale`、`limit`(1–100，默认 50) |
| `get_decision` | read | `GET /api/decisions/:id` | `decision_id` |
| `stop_check` | read | `GET /api/issues/:id/stop` | `task_id` |
| `ask_decision` | write | `POST /api/issues/:id/ask` | `task_id`、`request_id`(uuid 幂等键)、`question`、`options`(≥2)、`context_md?`、`trigger?`、`grace_seconds?`(0–600)、`checkpoint?`、`on_expire?`、`fence?` |
| `answer_decision` | write | `POST /api/decisions/:id/answer` | `decision_id`、`request_id`、`option`(序号或 label) 或 `text` 二选一、`revise?`、`expected_revision?` |
| `extend_decision_grace` | write | `POST /api/decisions/:id/extend` | `decision_id`、`request_id`、`seconds`(1–300，默认 60)、`by?`、`fence?`、`workspace_id?` |
| `withdraw_decision` | write | `POST /api/decisions/:id/withdraw` | `decision_id`、`request_id`、`reason`(必填)、`by?` |

- 一律 `.strict()` 校验；拒绝未知参数，避免拼写错误被静默忽略。
- `ask_decision` 需要 `AGENTBOARD_AGENT_ID`，缺失返回 `AGENT_ID_REQUIRED`；`fence` 同时作为请求体字段与 `x-claim-fence` 头。
- 所有写工具都要 `request_id`（幂等键，服务端按它防重放）。

## 2. 结果有界（防单次结果击穿 40k 上限）

- 列表只回摘要：`question` 窗口 2000 字符，不含 `context_md` / `checkpoint_json` / 完整 `answers`；`options` 仅保留 `id/ord/label/consequence/is_default`。
- 详情 `get_decision` 才回正文：`context_md` 窗口 12000、`checkpoint_json` 窗口 4000，并回 `answers` 全 revision 链与 `capabilities`。
- 截断时返回 `*_truncated` 与 `next_*_offset_chars`，客户端据此续读。
- `answer_decision` / `withdraw_decision` 先 GET 详情做工作区校验与 label 解析，返回体只回摘要 + 本次 answer/outcome。

## 3. 状态与 locked / stop_requested 语义

- 工具**不阻塞等待宽限**；`ask_decision` 只回 decision 快照。
- `locked = state === 'open'`，即 `grace_seconds=0` 时立即落锁（返回 `locked=true`、`stop_requested=true`），否则处于 `grace` 时 `locked=false`，轮询交给客户端（`get_decision` / `stop_check`）。
- 不新造状态机，完全沿用 ask-user 契约（默认宽限 180 秒，上限 600 秒）。

## 4. 答复（answer_decision）的人类身份约束

- 服务端 `answerPendingDecision` 强制 `answered_by='user'`，非 `user` 直接 403。MCP 固定发送 `answered_by: 'user'`、`source: 'cli'`，即把工具定位成「本机操作者代人类回答」，不是 agent 自答；权限由本地服务身份（`resolveActor` 默认 `user`=owner）授予。
- `option` 支持序号（`option_ord`）或 label（本地先 GET 详情解析成 `option_id`，找不到返回 `VALIDATION_ERROR`）；也可用 `text` 自由文本，二者只能给一个。
- 修订（`revise=true`）必须带 `expected_revision`，否则本地直接拒绝；服务端 CAS 不匹配返回 `DECISION_REVISION_CONFLICT`。返回 `outcome=answered|revised` 与最新 answer（含 revision）。

## 5. 宽限（extend_decision_grace）与撤回（withdraw_decision）

- 延长每次 1–300 秒，原始宽限 + 累计延长 ≤600 秒；仅 `state='grace'` 可延长，已落锁/已回答返回 `DECISION_NOT_GRACE`，超上限返回 `EXTEND_LIMIT_EXCEEDED`。
- 绑定工作区时一律带 `workspace_id`（显式传且与绑定不一致 → `WORKSPACE_BOUND`）；跨区延长由服务端 403。
- 撤回必须带 `reason`，仅 `grace/open` 可撤回（`answered/withdrawn` → `DECISION_NOT_ACTIVE`）；`by` 默认 `AGENTBOARD_AGENT_ID`，仅作审计标签。

## 6. 工作区绑定

- `list_decisions` 未绑定 `AGENTBOARD_WORKSPACE_ID` 时必须显式传 `workspace_id`，否则 `WORKSPACE_REQUIRED`。
- `get_decision` / `answer_decision` / `withdraw_decision` 返回的 `decision.workspace_id` 与进程绑定的工作区不一致时抛 `WORKSPACE_BOUND`，阻断跨工作区读写决策正文。

## 7. 错误码映射（服务端状态 → isError 安全码）

409 → `DECISION_ALREADY_OPEN` / `DECISION_ALREADY_ANSWERED` / `DECISION_REVISION_CONFLICT` / `DECISION_NOT_ACTIVE` / `DECISION_WITHDRAWN` / `DECISION_NOT_GRACE` / `EXTEND_LIMIT_EXCEEDED` / `ISSUE_STATUS_NOT_RUNNING`；400 → `ASK_TOO_FEW_OPTIONS` / `INVALID_GRACE` / `INVALID_SECONDS`；403 → `FORBIDDEN`；404 → `DECISION_NOT_FOUND` / `TASK_NOT_FOUND`。文本只回安全文案，不回服务端原文。

## 8. 真实调通方法（可复用的 MCP 验收通道）

1. 建一张临时卡并 claim（占用的 agent 名要与 `AGENTBOARD_AGENT_ID` 一致）。
2. 直接 `spawn` 构建产物 `apps/mcp/dist/index.js`，走 `initialize` → `tools/call`；参数含双引号时不要经 PowerShell 命令行传，改为写入 calls.json 文件（PS 5.1 会吞引号导致 `JSON.parse` 失败）。
3. `ask_decision` 用 `grace_seconds=0` 断言 `isError` 为空且 `locked=true`；宽限类用 180 秒再调 `extend_decision_grace` 断言 `extension_count` 递增。
4. 清理：先撤回未答决策，再 `kb delete-issue <临时卡> --yes`（`issue_decision` 对 `issue` 是 `ON DELETE CASCADE`，已答/已撤回决策随卡一起清掉）；卡被占用时先 `kb release`。
   历史坑：D1 时 `kb release` 曾报占用代次过期而 `delete-issue` 仍可用；D2 实测 release 正常，遇报错可直接删卡（决策表级联）。

## 9. 坑

- `MCP_TOOL_RESULT_LIMIT = 40_000`：详情工具必须做窗口截断，否则大 checkpoint 直接超限。
- alias 在注册器里统一产出，新增工具默认两倍计数；更新 `tools/list` 断言与 README 工具数时按 2× 主名核对。
- 并发回答：若另一路（Web/CLI）先回答了同一决策，首次 `answer_decision` 会拿到 `DECISION_ALREADY_ANSWERED`，紧接着的修订（带 `expected_revision`）仍可能成功。排查时看 `get_decision` 返回的 `answers[].source`（`web`/`cli`）与 `created_at`，不要误判成工具重放。
