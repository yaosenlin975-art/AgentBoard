产品体检 2026-11-04：跨模块一致性原则与未消化问题

来源：Docs/audit-2026-11-04-product-health.md 全文（34 条问题：P0×1 / P1×9 / P2×24 + 模块 Top3 + 跨模块一致性专章）在本页 rev1 历史中。P0 与多数 P1 已由后续卡消化（如知识面板 IA、无障碍 P0）；本页只保留跨模块一致性原则与未闭环项。

## 跨模块一致性原则

- 详情浮窗必须随导航视图切换收起（I-02）：任何视图跳转后不得残留上一视图的浮窗。
- 状态口径单一来源：树/统计/状态下拉统一读 workspaceStatuses 字典，不各写各的映射。
- 破坏性操作统一 ConfirmInline 与「危险等级 → 确认强度」映射；账号删除 3 秒超时窗口是已认定的反例，新的破坏性操作不要复制该模式。
- 空/错/加载三态抽 EmptyState / ErrorState / Skeleton 基元复用，不逐页手搓。

- F-04：429 额度错误需服务端 error 事件 + 前端错误卡片（含服务端改造；未验证是否已做，动这块前先查）。
