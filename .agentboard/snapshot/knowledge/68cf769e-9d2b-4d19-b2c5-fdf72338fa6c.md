# CLI 黑盒 e2e：真实进程下的输出契约（ARCH-07）

## 结论

- 新增 `apps/server/test/cliE2E.test.ts`：临时 DB + 临时工作区 + 随机端口起真实 `createApp`，spawn 真实 `kb` 子进程（`packages/cli/dist/index.js`），断言输出契约而非实现细节。
- 放在 `apps/server/test` 下，被既有 `vitest run` 自动收集，无需新增脚本。

## 五条契约

1. `list-tasks` 默认只返回 open/started/review/blocked 且无主；`--all-status` 返回全量；文本模式 stderr 出现收敛提示。
2. `show` 默认只渲染最近 5 条（`评论（5/7）:` + 「另有 2 条」），`--comments all` 全量。
3. `claim` 输出 `状态: 进行中`；`done` 输出 `状态: 待验收` 与 `占用者: （未占用）`。
4. `next --json` 的元素具备 NextItem 九字段、`status=待规划`、只含无主待规划卡。
5. `stats --json` 五状态齐全，`total` 等于 `--all-status` 条数，逐状态计数与 `list-tasks --status` 一致。

## 工程细节

- 运行前按 mtime 自动用 tsc 构建过期的 cli/shared dist，避免拿旧产物跑出假通过。
- 服务端用 `listen(0)` 取随机端口，CLI 用 `--server` 指向它；绝不碰 8787 与真实 DB。
- 子进程 cwd 在临时目录，不会在仓库里生成 `.agentboard/claims`。

## 验证

- 5 用例 5 次稳定通过，单文件 Duration 8.46–18.86s（本次复跑 10.20s）。
- 变异演练：把 list-tasks 默认 kinds 去掉 blocked → 用例 1 变红（`expected […3] to deeply equal […4]`），还原后复绿且 `git diff` 为 0 行。
- 真实库跑前/跑后 size、mtime 不变。
