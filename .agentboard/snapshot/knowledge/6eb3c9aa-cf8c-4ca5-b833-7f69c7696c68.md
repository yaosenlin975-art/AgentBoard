# 账号面板标题栏操作区:Portal 宿主与无宿主回退(ACC-UI-TOPBAR)

## 需求与约束
面板级动作(添加/一键签到/刷新)要进 drawer 标题栏(『账号管理 … 关闭』一行、关闭左侧),但三者的状态都活在 `AccountsPanel`(一键签到 controller、导入 mutation、协议清单);同时 `AccountsPanel` 大量单测独立渲染、无标题栏。

## 方案
- `DrawerPanel` 标题栏在关闭按钮左侧渲染空槽 `<div data-testid="drawer-header-actions" className="... empty:hidden">`,`ref={setActionsHost}` 回调 ref 把槽 DOM 节点存进 state,经 `DrawerHeaderActionsContext`(context 模块单放 `drawer/drawerHeaderActions.ts`,避免 DrawerPanel↔AccountsPanel 循环 import)下发给 body 里的面板。
- `AccountsPanel` `useContext` 拿宿主:**有宿主 → `createPortal(headerActions, host)`**;**无宿主(单测/独立渲染)→ 回退渲染 `data-testid="accounts-toolbar"` 内联行**(同一份 headerActions JSX,按钮组合一致)。空槽用 `empty:hidden` 收起(settings drawer 不显示空操作区)。
- 回退首帧(宿主 ref 回调 setState 前的一跳)被 drawer 160ms 滑入动画掩盖,无可感知闪烁。

## 坑
- `useMemo` deps 数组里引用**后声明的 const 会运行时 TDZ 崩**(闭包体内引用不报错、deps 数组是立即求值):`activeApp` 必须先算再进 indexItems 的 useMemo。`activeApp = selectedApp ?? APP_ORDER[0]`(indexItems 的 known 段恒为 APP_ORDER 且排最前,首项恒等)。
- `AccountsMasterDetail` 选中态上提用**可选受控 props**(`selected`/`onSelect` 不传保持内态),独立渲染口径不变。
- 顶栏『添加』只对装配了协议的当前平台出现(与平台内向导同一份 `/api/add-account-protocols` 查询,queryKey 共享);不可用走面板内 reason 文案,不出必败按钮。

## testid 口径(本卡裁决)
- 沿用:`accounts-add-<app>`(按钮位置移到标题栏/回退行,文案『添加』)、`accounts-one-click-checkin`、`accounts-import-local`、`accounts-add-panel-*`。
- 删除:`accounts-summary-*`(其中 N 个参与一键签到)、`accounts-capture-*`、`accounts-notice-*`、`accounts-one-click-plan`(计划摘要不上迁)。`✓✓✓` 能力三图标(CapabilityBadges)保留。
- 捕获 UI 入口整体删除;`POST /api/managed-accounts/:app/capture-current` API 保留,添加账号向导仍可用。

## 验证口径
- 测试页 5174 DOM 断言:drawer-header-actions 内恰为 添加/一键签到/刷新 三按钮且 `closeAfter`(关闭在其后);`accounts-toolbar` 回退行仅无宿主时存在;残留字样(个可签到账号/启用并参与一键签到/捕获)计数 0。
- 全量 vitest 的既有失败按「导入关系 + 失败栈」归因,不默认背锅:本卡波及 23 文件 151 用例全绿;8 个失败文件与本卡组件零 import 关联(chatSessionList 败于 3180fff DEC-BADGE 的 SideBar.tsx useQueryClient 无 Provider)。
