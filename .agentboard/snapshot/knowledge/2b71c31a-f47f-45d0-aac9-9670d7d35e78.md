# React Query 批次终态额度快照刷新

- `useCheckinBatch` 首次观察到批次 `finished_at` 后，先取消 `managed-account-quotas` 前缀下在飞查询，再失效 `managed-accounts` 与 `managed-account-quotas` 前缀；聚合额度和账号级额度共用该额度前缀。
- 当前安装版本中，active query 尚无缓存数据、首次请求在飞时，单独调用 `invalidateQueries` 会复用该请求；旧响应可能成为新数据。`cancelQueries` 后再失效会启动新的请求，取消前的迟到结果不覆盖新快照。
- 批次按 `finished_at` 进入终态，原有轮询在终态停止；刷新逻辑只在批次 id/终态时间变化时触发一次。
- `apps/web/src/test/checkinRunPanel.test.tsx` 通过 QueryClient 与 MSW 挂起首次聚合/账号级额度响应，覆盖新请求、旧响应迟到、列表刷新及终态停止轮询。
