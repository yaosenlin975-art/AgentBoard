# MCP 工具注册收敛与错误文案保真（CR2-8）

## 背景
六域 `tools/*.ts` 各自复制 register 包装（try/catch + 成功包装 + `agentboard_` 前缀 alias），`result.ts` 把非 McpError 一律塌成 `UPSTREAM_ERROR` 通用文案，业务错误原文到不了客户端。

## 方案
- 新增 `apps/mcp/src/tools/register.ts`：`registerBoardTool(server, spec, run)` 统一 handler try/catch、成功包装、主名 + `agentboard_<name>` alias 注册；`spec.readOnly` 控制 readOnlyHint（默认 true）；`spec.onResult` 只在写工具需要裁剪结果时覆写（任务写结果走 `boundedMutationData`）。
- `result.ts`：McpError 直通；普通 Error 透传 message 原文（空 message 回退通用文案）；非 Error 回退通用文案。
- alias 去留仍归 f78d7465，本卡保持 alias 数量不变。

## 验证
- `apps/mcp`：`npx vitest run` → 7 文件 75 用例全绿（含错误码/文案单测）。
- `npx tsc -p tsconfig.build.json --noEmit` → exit 0。
- `npm run list-tools` → 主名 40、alias 40，主名集合不变。

## 坑
- 局部 `register` 帮手删掉却留下旧式 4 参调用时，只有运行期才炸（initialize 直接返回 Internal server error），测试会表现为「协议版本 undefined」这种误导性断言。
- `tsc --noEmit` 默认含 test 目录会报一堆存量可选链告警；包内构建口径是 `tsc -p tsconfig.build.json`，只校验 src。
