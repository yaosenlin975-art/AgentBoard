# 顶栏结构：单行 TopBar 的布局预算与功能归宿（TOPBAR-REDESIGN）

## 范围与结论

- 全局顶栏早在 NAV-TOPBAR-01 就已移除，左栏 SideBar 是唯一导航；看板/任务树页面最上方那条是**视图工具条**，不是全局顶栏。
- 2026-11-10 起由 `apps/web/src/components/shell/TopBar.tsx` 承载，旧 `components/ui/ViewToolbarShell.tsx` 已删除；替换点只有 `Board.tsx` 的一处组件调用，可整段回退。
- 结构：`header[data-testid=view-toolbar-shell]`（`bg-surface-card` + `border-b border-hairline` + `px-4 py-2`）→ `div[board-toolbar-row]`（flex-wrap）三个区：
  - 左：`topbar-crumb`「工作空间名 › 视图名」（工作空间名 11.5px ink-3，视图名 12.5px 半粗 ink）；
  - 中：`board-toolbar-filters` = 搜索框 + `LabelFilterBar`；
  - 右：`board-toolbar-controls`（`ml-auto`）显示密度、分组方式、选择、任务树「+ 新建任务」。
- 桌面（>920px）单行 47px；≤920px 时 filters 容器降级为 `display:contents`，第一行「面包屑 + 搜索 + 控件」，第二行标签整行，实测 79px。

## 宽度预算（改顶栏前先算这笔账）

1440 视口 + 侧栏 176 展开 → 内容宽 1232（px-4 两侧各 16）。

- 面包屑约 86，搜索 144（`w-36`），右端三控件约 230；剩余约 724 给标签区。
- 14 个 chip（本工作区实测约 617px）+ 14 个 4px 间距 + 「更多 +N」约 73 → 约 750，比 724 多 26。
- 保持单行的三处收敛：搜索 `w-40`→`w-36`（-16）、行内 `gap-x-3`→`gap-x-2`（-8）、filters `gap-2`→`gap-1.5`（-2）。
- 结论：**新增右端控件、或把搜索加宽超过约 40px，标签就会换到第二行**。若第二行只剩「更多 +N」孤零零一个 chip，说明预算又不够了，优先收搜索/间距，不要给标签区加横向滚动。
- `LabelFilterBar` 的硬约束不变：容器不得 `overflow-x-auto`（会裁掉「更多」绝对定位浮层），只能换行；桌面两行封顶、≤900px 直接换行。

## 功能归宿

| 旧入口 | 归宿 |
| --- | --- |
| 显示密度 / 分组方式 / 选择 | 新顶栏右端 controls（同 testid、同行为） |
| 任务树「+ 新建任务」 | 新顶栏右端 controls，仅任务树出现 |
| 搜索标题/描述/标签 | 新顶栏中段 filters，testid `board-search` |
| 标签筛选 chips | 新顶栏中段 filters，`board-toolbar-chips` 容器保留 `min-w-0` |
| 窗口/主题/设置/同步状态 | 本来就在左栏 SideBar 底部，不在这条上 |
| 知识库 / 日志的空工具条 | 不再挂空壳（TOOLBAR-BLANK），锚点 testid 改为 sr-only |

## 测试与可回退性

- 保留全部既有 testid：`view-toolbar-shell` / `board-toolbar-row` / `board-toolbar-controls` / `board-toolbar-filters` / `board-toolbar-chips` / `board-search`；`topbarTabs.test.tsx` 依赖外壳的 `px-4 py-2` 与视图根节点无内边距，改壳时不要动这两点。
- 回归命令：`pnpm --filter @agentboard/web exec vitest run src/test/topbarTabs.test.tsx src/test/toolbarBlank.test.tsx src/test/board.test.tsx` → 40 passed。
- 构建：`pnpm --filter @agentboard/web build` 与 `pnpm publish:web` 均通过（含 check-bom）；8787 正式页实测 shell 高 47px。
- 另有 9 条用例在 HEAD 基线即失败（dispatchTemplate / knowledge* / newIssuePlus / modalFocusLoop / chatSessionList），与本改动无关，别误判成顶栏回归。

## 坑

- 测量用 `http://localhost:5174`：本机 vite 只监听 localhost，`127.0.0.1:5174` 连不上（与测试页 README 的写法不一致，按实际连通性为准）。
- 摘面包屑的工作空间名不要超过 `max-w-40`，长工作区名会挤掉标签区宽度。
- 窄屏第一行的搜索框用 `flex-1` + `min-w-32`，不要再给固定宽度，否则 900px 下会把右端控件挤到换行。
