# 顶栏结构：单行 TopBar 的布局预算与功能归宿（TOPBAR-REDESIGN / TOPBAR-02）

## 范围与结论

- 全局顶栏早在 NAV-TOPBAR-01 就已移除，左栏 SideBar 是唯一导航；看板/任务树页面最上方那条是**视图工具条**，不是全局顶栏。
- 2026-11-10 起由 `apps/web/src/components/shell/TopBar.tsx` 承载，旧 `components/ui/ViewToolbarShell.tsx` 已删除；替换点只有 `Board.tsx` 的一处组件调用，可整段回退。
- **TOPBAR-02（同日）删除了左侧面包屑**：`topbar-crumb`「工作空间 › 视图」整块移除，`TopBar` 不再收 `workspaceName` / `viewLabel`；`Board` 的 `workspaceName` prop 一并删除，`App` 不再传。当前「在哪个工作区 / 哪个视图」由左栏承担：`sidebar-workspace` 显示工作区名 + 路径，五个入口用 `aria-current="page"` + `bg-accent-soft` 高亮 —— 判定为已够，**不要为补偿再新增控件**。
- 结构：`header[data-testid=view-toolbar-shell]`（`bg-surface-card` + `border-b border-hairline` + `px-4 py-2`）→ `div[board-toolbar-row]`（flex-wrap）两个区：
  - 中（现在从行首开始）：`board-toolbar-filters` = 搜索框 + `LabelFilterBar`；
  - 右：`board-toolbar-controls`（`ml-auto`）显示密度、分组方式、选择、任务树「+ 新建任务」。
- 桌面（>920px）单行 47px；≤920px 时 filters 容器降级为 `display:contents`，第一行「搜索 + 控件」，第二行标签整行（实测 78px 左右）。
- 待决策视图（`DecisionsView`）页头同口径：`<h1>待决策</h1>` 与 `decisions-total` 总数徽标一并删除，页头只剩筛选 tab（含分项计数）+ 排序 / 范围；不要再加回标题。

## 宽度预算（改顶栏前先算这笔账）

1440 视口 + 侧栏 176 展开 → 内容宽 1232（px-4 两侧各 16），filters 左边界实测 192。

- 删面包屑前：面包屑约 86 + 搜索 144（`w-36`）+ 右端三控件约 230，剩余约 724 给标签区；14 个 chip（约 617px）+ 14 个 4px 间距 + 「更多 +N」（约 73）≈ 750，**超 26 → 曾靠收搜索与间距硬塞**。
- 删面包屑后：省下约 86 + 行间距 8，标签区预算回到约 858，14 个 chip 的单行余量约 110。
- 结论：**新增右端控件、或把搜索加宽超过约 100px，标签才会换到第二行**。若第二行只剩「更多 +N」孤零零一个 chip，说明预算又不够了，优先收搜索/间距，不要给标签区加横向滚动。
- `LabelFilterBar` 的硬约束不变：容器不得 `overflow-x-auto`（会裁掉「更多」绝对定位浮层），只能换行；桌面两行封顶、≤900px 直接换行。

## 功能归宿

| 旧入口 | 归宿 |
| --- | --- |
| 显示密度 / 分组方式 / 选择 | 新顶栏右端 controls（同 testid、同行为） |
| 任务树「+ 新建任务」 | 新顶栏右端 controls，仅任务树出现 |
| 搜索标题/描述/标签 | 新顶栏中段 filters，testid `board-search`，现从行首开始 |
| 标签筛选 chips | 新顶栏中段 filters，`board-toolbar-chips` 容器保留 `min-w-0` |
| 工作空间 › 视图 面包屑 | **已删除（TOPBAR-02）**，由左栏工作区名 + 入口高亮承担 |
| 待决策标题 + 总数徽标 | **已删除（TOPBAR-02）**，由左栏入口高亮 + tab 分项计数承担 |
| 窗口/主题/设置/同步状态 | 本来就在左栏 SideBar 底部，不在这条上 |
| 知识库 / 日志的空工具条 | 不再挂空壳（TOOLBAR-BLANK），锚点 testid 改为 sr-only |

## 测试与可回退性

- 保留全部既有 testid：`view-toolbar-shell` / `board-toolbar-row` / `board-toolbar-controls` / `board-toolbar-filters` / `board-toolbar-chips` / `board-search`；`topbarTabs.test.tsx` 依赖外壳的 `px-4 py-2` 与视图根节点无内边距，改壳时不要动这两点。
- `topbar-crumb` / `decisions-total` 已不存在，不要再按这两个 testid 写断言；`decisionsView.test.tsx` 里原来断言徽标文本 '6' 的用例已改为断言其不存在。
- 回归命令：`pnpm --filter @agentboard/web exec vitest run src/test/topbarTabs.test.tsx src/test/toolbarBlank.test.tsx src/test/board.test.tsx src/test/decisionsView.test.tsx src/test/App.test.tsx src/test/taskTree.test.tsx` → 142 passed。
- 构建：`pnpm --filter @agentboard/web build` 通过（含 check-bom）；重建 dist 后 8787 实测 shell 高 47px、不含 `topbar-crumb`、无残留 `border-r`。
- 全量 `pnpm --filter @agentboard/web test` 有 7 个文件 / 8 条用例失败（dispatchTemplate、detail 的 DispatchDialog、knowledge / knowledgeHistory / knowledgeSlugResolve / knowledgeStyle、chatSessionList），这些文件都不引用 `Board` / `TopBar` / `DecisionsView`，属 HEAD 基线与并行进行中的派发/知识库改动，别误判成顶栏回归。

## 坑

- 测量用 `http://localhost:5174`：本机 vite 只监听 localhost，`127.0.0.1:5174` 连不上（与测试页 README 的写法不一致，按实际连通性为准）。要验重建后的 dist 则直接用 `127.0.0.1:8787`（需先 `pnpm --filter @agentboard/web build`）。
- 窄屏第一行的搜索框用 `flex-1` + `min-w-32`，不要再给固定宽度，否则 900px 下会把右端控件挤到换行。
- 8787 页面用 Playwright 打开前要先把工作区塞进 localStorage（`agentboard.selected-workspace` = `{"state":{"workspaceId":"<id>"},"version":0}`），否则落到未选工作区态、等不到 `board-toolbar-row`。
- 侧栏工作区切换按钮默认拿焦点，会在截图里留下 2px accent 焦点环；截图脚本先 `document.activeElement.blur()` + 移开鼠标，不然会误以为是顶栏残留描边。
