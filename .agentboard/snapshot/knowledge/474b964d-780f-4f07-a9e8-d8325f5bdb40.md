# 账号页左栏口径：只列有账号的平台（口径 A）

## 结论（2026-11-07 用户拍板）

- 工具栏放**唯一**「添加账号」入口，打开供应商选择页（7 卡）。
- 左栏只列**有账号**的平台/来源；零账号平台不占位。
- 「哪些平台能添加」只由添加页呈现；左栏定位收敛为「已有账号的索引」。

## 与两套原型的关系

- 采纳 ccounts-add-flow-2026-11-05 的左栏过滤 + 全局添加入口 + 7 卡选择页（其 DESIGN-NOTES §1、§4 的 Q1=A、Q2=A）。
- 采纳 ccounts-redesign-2026-11-04 的 244px 左栏宽、指标迷你条、额度进度条、删除能力徽标。
- 作废 ccounts-redesign-2026-11-04 的「六平台常驻、零账号也占位」（DESIGN-NOTES.md:69-70）。

## 为什么

1) 添加账号是低频动作，不需要六个常驻空行承载入口；
2) 左栏一旦兼作「添加入口 + 平台索引」两种职责，空行会被误读为「该平台已接入」；
3) 过滤后新增账号会让平台自动出现，索引与数据天然一致，无需额外空态降级分支。

## 落地约束

- 左栏数据源：pps/web/src/components/settings/AccountsMasterDetail.tsx，改成「账号数 > 0 的平台/来源」；含停用账号仍算有账号。
- 添加入口：pps/web/src/components/settings/AccountsPanel.tsx 工具栏唯一按钮；行内 AddAccountEntry 迁出。
- 空态：没有任何账号时左栏给一条引导，右栏空态引导点「添加账号」，不保留按平台的空行。
- 原型 HTML/app.js 的历史 mock 不回改；本页只描述落地口径。
