# Command Code 账号级额度接入

## 目标与来源
为已登记的每个 Command Code CLI 账号读取真实 credits 与 5h/weekly 使用窗口。CLI 账号之间不聚合，结果沿用 QuotaResult/QuotaSnapshot；不改全局平台额度快照。

官方 npm 发布包 command-code@1.88.5 的 dist/cli.mjs 内 /usage overlay 读取账号计费接口，Authorization 使用 Bearer API key，默认服务为 https://api.commandcode.ai。使用 whoami?limits=1 获取可选 orgId，再请求 billing/credits；/usage 还会读取 subscriptions 与 usage/summary，但本功能不使用它们。command-code@1.88.5 是完整交互 CLI bundle，package.json 标记 UNLICENSED 且没有公开 SDK 元数据，不作为运行时依赖。

## 共享契约
QuotaSourceId 增加 commandcode，source group 为 cli，标签为 Command Code 余额，单位为 credits。此来源仅按 cli_account id 查询，不进入 QUOTA_GROUPS、QUOTA_SOURCE_IDS 或全局 QuotaCards 顺序；既有八个全局聚合来源不变。QuotaWindow 的 reset_at 沿用 epoch 毫秒或 null。

## 服务端数据流
新增 GET /api/cli-account-quotas?account_id=<uuid>。路由只读 cli_account 指定行，要求 app_id=commandcode；该表没有 enabled 字段，不构造额外状态筛选。路由不调用 /api/cli-accounts，不触发本机凭据发现或 last_seen_at 更新。

凭据仅从该行 credential_ref 解密，vault scope 为 app_id=commandcode、CLI_CLIENT_INSTANCE_ID、该行 identity_hash、purpose=cli_credential。缺少 ref 或解密失败时返回非 ok 的额度结果，不读其它账号、不用 managed_account 或当前本机 key 兜底。

额度查询按 source+cli_account id 做缓存隔离。只向固定官方 HTTPS host 发只读 GET：先请求 /alpha/whoami?limits=1，若返回组织 id 则按 CLI 契约加 orgId 查询 /alpha/billing/credits，否则省略该参数。窗口优先使用这两份响应中实际提供的 windowLimits.fiveHour/weekly，不请求 subscriptions、usage/summary 或其它端点。

credits.monthlyCredits、purchasedCredits、freeCredits 必须全部存在且为有限数值，balance 为三项之和，缺失字段不补零。只有完整有效响应中的真实数值 0 才是 status=ok 且 balance=0。fiveHour 与 weekly 均从 windowLimits 的 used、cap、resetAt 映射：total=cap、used=used、remaining=cap-used、kind 分别为 rolling/weekly；resetAt 为 0 时 reset_at=null，其它有效值按 epoch 毫秒原样传递。

无账号返回 404。无 credential_ref 返回 unsupported/CREDENTIAL_MISSING；保险库读取失败、401、403、网络失败和响应结构缺失分别回报非 ok 状态与原因码，balance=null，不返回零余额。403 表示服务拒绝/无 allowance，不冒充用量为零。

## 界面
账号管理 Command Code 详情为每个 PublicCliAccount 独立查询 GET /api/cli-account-quotas?account_id=<id>，queryKey 包含该 account id。仅在 status=ok 时显示余额和两个窗口；错误、无凭据、空数据使用明确状态。Command Code 不加入全局 QuotaCards 聚合列表。

## 验收与拆分
Shared 契约先完成；server 路由/凭据/额度与 web 每账号展示共享该契约，目标文件不相交，可在 Shared 关闭后并行。server 必须用 createApp 实测路由非 404，并覆盖不同账号缓存隔离、缺凭据、401、网络/坏结构、真实零余额和 resetAt=0。UI 测试验证每行独立 queryKey/URL、错误不渲染为零。真实来源 200 探针已在本工作区 B 卡评论记录；实现复用该证据，不重复请求。
