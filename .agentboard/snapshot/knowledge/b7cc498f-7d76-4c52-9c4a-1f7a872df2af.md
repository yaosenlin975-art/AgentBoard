# 知识库运营技能（kb-curator）：主题页维护口径

## 核心约定

- 一个主题一页：第二次投喂同主题链接走 `kb knowledge revise` 追加，不新建重复页。
- 新主题才 `create`，且 `--domain` 必填、`--category` 显式给出，sources / evidence 各 ≥1。
- 合并重复主题用归档，不删除历史页。

## 坑

- `revise --sources` 是整组替换：只传新来源会把旧来源挤掉，必须把新旧来源一起重新提交。
- `--expected-revision` 是 CAS：旧值退出码 2，需重新 `show` 取当前 revision 再改。
- file 来源不带 snapshot（服务端拒绝），url 来源 snapshot ≤2 KiB，只放摘要不放整段正文。

## 与相邻技能分工

- 抓取、反爬、多引擎检索归 web-scout；本技能只负责摘要、征询入库与主题页维护。
- 设计页写入归 brainstorming，本技能不替代。

## 快速查找

`kb knowledge search <关键词>` 命中页后，`kb knowledge show <id>` 读正文，或把 `knowledge:<id>` 链接直接发给他人。
