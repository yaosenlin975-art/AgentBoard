# 便携包打包的软链决策口径（CR-13）

## 契约

- `scripts/package-portable.mjs` 的 `copyTree` 改为 lstatSync 显式决策，不再 statSync 盲目跟随：
  - 文件软链 → 解引用复制并计数（保持「不漏文件」语义）；
  - 目录软链（含 Windows junction）→ 跳过并计数（根路径例外：调用方显式指定的来源目录是 junction 时解引用进入，技能目录场景不回归）；
  - 悬空软链 → 跳过并计数。
  - 目录软链一律跳过后，遍历只走真实目录树，结构上不可能因软链成环或把目标整树展开。
- 每次目录软链/悬空跳过当场打日志；打包结束统一打印「软链处理：解引用 X 个，跳过 Y 个」+ 前 20 条路径（`logSymlinkStats`）。
- 记录用仓库相对路径（正斜杠），不落绝对路径进日志。

## Windows 验证手法（可复用）

- `cmd //c "mklink /J <link> <target>"` 建 junction（无需管理员权限）；`mklink`（不带 /J）建文件符号链接（本机可用，开发者模式/特权已具备）。
- 坑：`mklink` 的 target 是**相对链接所在目录**解析的，不是相对当前工作目录——在仓库根用相对路径建「指向父目录」的链接会变成悬空链。要用绝对路径。
- 构造测试软链放 `apps/web/dist`（构建产物、git 忽略、pnpm -r build 会重建），copyTree 真实走到它；测完 `rm` 链接 + `rm -rf dist-package`。
- 指向父目录的 junction 若被跟随会 dist→apps/web→dist 无限递归；修复后运行打包秒过并打印跳过记录。

## 边界

- `walk()`（manifest 清单）本就按 Dirent 不含软链，未改。
- 非 Windows 场景未测（脚本目标 Windows x64）。
