# OpenCode Go usage source

## Credential lookup
- OpenCode v2.2.5 resolves the current active `opencode` integration connection. Its credential is stored in the OpenCode SQLite `credential` table.
- OpenCode data path follows `XDG_DATA_HOME` or the user data directory; `OPENCODE_DB` overrides the database path, with relative overrides under the OpenCode data directory.
- Read only `credential.value` for `integration_id='opencode'`, ordered by `active DESC, time_created DESC, id DESC`; do not scan session or message tables.
- OAuth uses `access`; API credentials use `key`; both require `metadata.orgID`. Never refresh credentials or write OpenCode DB/auth/service files.
- Normalize the legacy `console.opencode.ai` host to `opencode.ai`; send credentials only to the fixed official HTTPS Go endpoint. An unsupported Console host is not contacted.

## Request and fallback
- Windows without explicit `OPENCODE_SERVER_URL` uses the current active Console credential and `GET https://opencode.ai/zen/go/v1/usage` with Bearer authorization and `x-opencode-org-id`.
- Windows `.NET HttpClient` uses the system proxy and default TLS certificate validation, disables redirects, and has a 12-second timeout. The PowerShell script is static command input; credential payload is sent through stdin.
- An explicit `OPENCODE_SERVER_URL` uses the existing local `/api/experimental/usage/limits` route. Missing or unreadable Console credential also falls back to that existing route. Direct upstream 401, 403, 429, server errors, and network failures are returned as such; they do not trigger fallback or become zero usage.
- Non-Windows continues using the existing local service route. No client or service is started automatically.

## Result mapping and identity boundary
- Official response windows are `rolling`, `weekly`, and `monthly`, each with `status`, `percent`, and ISO string `resetsAt`. `percent` is used percentage; zero is valid. Parse `resetsAt` with `Date.parse()` into epoch milliseconds for `QuotaWindow.reset_at`.
- `rate-limited` retains the existing limited notice. HTTP 403 means no Go allowance and maps to `unsupported`; this endpoint provides usage windows, not a monetary balance, so `balance=null` and `unit='%'`.
- The credential lookup follows OpenCode's current active integration. An `account_id` cache key remains isolated but does not select a different OpenCode integration credential; do not present this source as per-managed-account credential selection.
