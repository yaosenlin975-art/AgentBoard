# macOS 托盘 Template 图标（tray-icon 18pt 归一与深浅色适配）

## 坑：彩色托盘图在 mac 菜单栏几乎不可见

macOS 菜单栏图标惯例是单色 Template Image（黑 + alpha，`setTemplate(true)` 后由系统按菜单栏深浅色自动反色）。直接沿用 Windows 的彩色 tray.ico 在 mac 菜单栏不随前景色变化、视觉上「未见明显图标」。

## tray-icon 的 18pt 归一（选资产的依据）

tray-icon 0.25.1（Tauri 2.12 锁定版）在 macOS 上恒把托盘高度归一到 **18.0 逻辑点**：`nsimage.setSize((w/h*18, 18))` 后再 `setTemplate(flag)`。因此：
- 不需要也不能依赖 PNG 的 DPI/pHYs 元数据——Tauri `Image::from_bytes` 解码成 RGBA 后元数据丢失。
- 资产按物理像素给：1x=16px、@2x=32px（18/36 物理像素近似），运行时按 `primary_monitor().scale_factor()` 二选一嵌入；单给 16px 在 retina 会放大发糊，单给 32px 在 1x 屏轻微下采样（也可接受）。

## 接线要点（desktop/src-tauri/src/main.rs）

- 平台分流函数 `tray_icon_bytes(app)`：mac 按 ScaleFactor 选 `icons/tray.png` / `icons/tray@2x.png`，其它平台返回 `icons/tray.ico`（Windows HICON 行为不变）。
- `.icon_as_template(cfg!(target_os = "macos"))`：`cfg!` 是编译期 bool、两侧平台都在链式调用里编译通过，不需要 `#[cfg]` 分支 Gymnastics；该开关在非 mac 平台无效。
- Template 资产生成：从 tray.ico 提取 16/32 帧，白列→黑列、彩底→1px 黑描边环（形状阈值 alpha≥160 过滤掉底部阴影层），生成脚本口径见卡 6ee1e11c 评论。

## Windows 侧验证法（不动线上 8787 服务）

隔离 `APPDATA` + `config.json{port:8790}` 后跑 dev 二进制 `--probe-tray-ms 3000 --probe-out <json>`：探针走 hide→wake_main_window（与托盘左键同函数）并断言 after_wake.visible/focused=true；退出码 0、8790 无监听、APPDATA 下 server.lock 清理。方法细节见 [Tauri 壳验收](knowledge:9f5ad69c-a7e8-446c-8789-cda63437b946)。
