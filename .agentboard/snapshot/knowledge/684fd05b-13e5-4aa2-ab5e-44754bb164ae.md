# 桌面壳开机自启：与 CLI 共用入口、owner 判定与 Tauri v2 ACL 放行

## 入口（三平台必须与 CLI 同一项）

- Windows：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 值名 `AgentBoard`，值 `"<安装目录>\AgentBoard.exe" --autostart`。
- macOS：`~/Library/LaunchAgents/com.agentboard.server.plist`（label 与 CLI 相同），`ProgramArguments=[<app exe>,"--autostart"]`、`RunAtLoad=true`、`KeepAlive=false`；写入后先 `launchctl bootout gui/<uid>/com.agentboard.server` 再 `bootstrap gui/<uid> <plist>`。
- Linux：`~/.config/systemd/user/agentboard.service`，`ExecStart="<app exe>" --autostart`、`Restart=no`，`systemctl --user enable --now agentboard.service`。
- **不要用 `tauri-plugin-autostart`**：它另建注册入口（mac 另 label），会与 CLI 的自启项并存成两项。

## owner 判定（决定置灰与冲突）

- 按入口内容判：`--autostart` 且 exe stem 匹配 → `desktop`；`agentboard.vbs` / node 起 `apps/server/dist/index.js` → `cli`；同键指向别的程序 → `other`；读失败 → `unknown`。
- `enabled` 仅在 `desktop` / `cli` 时为 true；`none` = 未安装。
- 读失败只落 `error` 字段，不 reject；只有 IPC 本身失败才 reject。
- `autostart_set` 契约表：`enabled=true` 时 `none`/`desktop` 写、`cli` 需 `takeOver` 否则 `AUTOSTART_CONFLICT`、`other` 一律 CONFLICT；`enabled=false` 时 `desktop` 删、`cli`/`other` 返回 `AUTOSTART_NOT_OWNED`、`none` 幂等 Noop；`unknown` 拒绝写（`AUTOSTART_IO`）。
- `supported`：`tauri::is_dev()` 为 true（未启用 custom-protocol 的构建，即 tauri dev / 普通 cargo build）→ false；只有已安装运行才允许写。

## Tauri v2 ACL 事实（坑）

- 应用一旦定义了 capability（存在 app ACL manifest），**应用自定义命令默认被拒**：实测返回 `autostart_status not allowed. Plugin not found`。`invoke_handler` 只负责挂命令，不负责放行。
- 放行方式：`src-tauri/permissions/<name>.toml` 里定义
  `[[permission]] identifier="allow-autostart-status"` + `commands.allow=["autostart_status"]`，
  再在 capability 的 `permissions` 数组引用（应用权限无前缀，不写 `app:`）。
- capability 的 `remote.urls` 决定远程页面（`http://127.0.0.1:8787`）能否命中。壳端口可配（CR-6），别的端口不命中；验证自定义端口要临时把测试 URL 加进 `remote.urls`、验完还原，不能把测试端口留在产品 capability。

## `--autostart` 语义

- 登录拉起后不 `window.show()`（窗口创建时 `visible(false)`），只驻留托盘；server 仍走 `ensure_server` 既有逻辑。
- 可见性验证用 `EnumWindows` + `IsWindowVisible` 按 pid 枚举，主窗口 title=`AgentBoard`；**不要用 `Process.MainWindowHandle`** —— 它会命中单例插件的隐藏消息窗口（`com.agentboard.desktop-siw`）。

## B11 对齐

- `launchagent_custody()` 要读 plist 内容：含 `--autostart` = 桌面托管，server 由壳自拉，不等 15s launchd 宽限；不含则维持 CLI 托管语义（宽限、退出不停服）。否则桌面自启每次登录都要空等 15s。

## 无头验证方法（Windows，真机 IPC）

- 设 `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9333` 启动壳 → `GET http://127.0.0.1:9333/json` 取 page target → Node 全局 `WebSocket` 连 `webSocketDebuggerUrl` → `Runtime.evaluate`（`awaitPromise:true, returnByValue:true`）执行 `window.__TAURI_INTERNALS__.invoke('autostart_status')`。
- 这一条链路同时验证：页面注入可用、`invoke_handler` 已注册、ACL 已放行、命令实现真实执行；比单测或“看代码注册了”强。
