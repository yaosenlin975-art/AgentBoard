# routes.ts 按域拆分：纯搬迁模式与验证套路（CR-10）

## 搬迁模式
- 域文件放 `apps/server/src/api/routes/<域>Routes.ts`，导出 `create<域>Router(deps)` 工厂，沿用 api/ 下既有域文件惯例（deps 接口 + 工厂，先例：accountRoutes / issuePayloadRoutes）。
- STORE-1/4a 解析闭包（workspaceResolverDeps / requireWorkspaceRow / dbForWorkspace / locateIssueRouted / requireIssueRouted / locateSessionRouted / resolveRequestDb / effectiveWorkspace / mutation / currentDbPath / attachmentsDirOf）是 routes.ts `createRouter` 装配期闭包、多域共用：留在 routes.ts，经 deps 接口注入域工厂，不在域内重建。
- parseBody / requireWorkspaceParam / requireExistingWorkspace 等小 helper 随域本地复制（api/ 既有先例：accountRoutes 自带 parseBody）；提取公共 helper 受本轮卡面文件白名单限制（只许改 routes.ts + 新建 routes/<域>Routes.ts），留作拆分完成后的可选收敛项。
- 仅类型位置引用的 repo 函数（`ReturnType<typeof getIssue>` / `typeof getSession` 作 locate* 闭包的载荷类型）在 routes.ts 保留 value import，即使域端点已全部迁出。

## 顺序约束（语义保持的关键）
- CR-10a（issues）：DEC-WIRE——决策路由必须在 /issues/:id 中间件之前注册。整域单点挂载时，`router.use(createIssueRouter(...))` 放在 `createDecisionRouter` 之后；决策路由无 2 段 `/issues/*` 路径，draft 从决策路由前挪到后无路径冲突。域内相对顺序保持：draft 先于 /issues/:id 中间件（'draft' 不被当成卡 id）；/issues/counts 先于 GET /issues/:id。
- CR-10b（workspaces）：整域挂载点取原 per-workspace changelog 子挂载处（per-workspace changelog/statuses 子挂载随域搬入域工厂）；该位置此前无任何路由含 /workspaces/* 业务路径，决策路由的 /workspaces/:workspaceId/decisions/* 在其后注册且本域无 'decisions' 字面路径，前后无冲突。express.raw（附件上传）随域搬迁。
- CR-10c（sessions）：整域挂载点取原 sessions 群起点（clis 之后），域内端点原本连续，单点挂载零顺序影响；fileAttachmentPromptBlock（导出函数）随域搬迁并保持导出。
- 无前缀 `router.use(子路由)` 下 req.baseUrl/req.path 与原注册同形：幂等 resource（baseUrl+path）与 /issues/:id 中间件内的 req.path 相对化（挂载前缀 '/issues/:id' 剥离出 '/claim' 等）均不受影响。

## 验证套路（每域同款）
- tsc：src 零错误。test/ 基线报错不扩大的证明法：`git stash push -- apps/server/src/api/routes.ts` 前后各跑一次 tsc，报错清单 diff 逐字一致（CR-10a/10b/10c 实测 118=118）。
- vitest 全量：`cd apps/server && npx vitest run --maxWorkers=4`（CR-10a/10b/10c 实测 167 文件 / 1616 用例全绿）。
- 端点对比（不起 live 实例）：一次性探针测试（createApp + supertest + git init 的临时空间目录），stash 前后各跑一遍，输出归一化 JSON 后 diff 逐字一致（CR-10a：issues 域 16 探针点；CR-10b：workspaces 域 14 探针点；CR-10c：sessions 域 14 探针点，含自由会话 CRUD/PATCH 归档/fork/重复删 404/缺参 400）。
- 归一化清单（防伪 diff）：uuid 与内嵌 uuid（knowledge_hint.message 里有 workspace uuid）、13 位毫秒时间戳（数字与字符串两种形态：claim_lease_until/last_heartbeat_at 是数字）、pid / db_path / db_scope / git_commit / comment / claimed_at / created_at / updated_at / 临时目录随机后缀（agentboard-probe-space-*、agentboard-test-*）。
