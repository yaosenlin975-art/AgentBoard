- 调研问题：拆解 llm_wiki 的分层架构、核心算法与数据结构、接口契约、知识生命周期及多 agent/MCP 协作边界。
- 用途背景：为 AgentBoard 的共享知识库设计讨论提供技术现状材料；范围已确认包含项目知识隔离与通用经验公共库。Codex、DSH、WorkBuddy 等 agent 通常写入资料，用户查看，agent 在编写项目代码时读取；当前任务中两类知识一起检索。此用途属于接收方需求，不代表 llm_wiki 已实现该能力。
- 范围内：指定仓库当前源码、数据流、持久化与检索路径、外部接口、知识写入/更新/删除生命周期、agent 与 MCP 的读写边界；接收方现状见 `findings/T0-接收方.md`。
- 范围外：修改 AgentBoard 或 llm_wiki 产品、安装依赖、引入或复制第三方代码、提交 Git；未确认的共享策略与产品取舍不在本轮定案。
- 假设：本轮按指定 GitHub 仓库固定快照取证；AgentBoard 是拟讨论的接收方；共享使用者包括多个 LLM 工具中的 agent 与人类用户，不预设多人团队协同。
