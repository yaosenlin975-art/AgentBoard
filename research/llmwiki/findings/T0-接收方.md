## Agent 接入与上下文注入

- 当前 agent 接入路径为 `kb` CLI → 本地 HTTP API；README 将 MCP server 记为二期，当前模块清单没有 MCP server 包或服务代码。`README.md:24-48`、`Docs/设计文档.md:12,209-217,313-318`、`Docs/DESIGNS.md:9-19`
- 用户提及的 WorkBuddy 未出现在 AgentBoard README 的四家 CLI 清单中；具体 CLI 名称、版本和接入方式尚无本地证据。`README.md:1-9`


- UI 派发模板包含 issue id、标题、描述、workspace 路径，并在未预置历史备注时追加该 issue 最近 10 条评论；模板允许调用方提供替代版本。`apps/server/src/services/dispatch.ts:18-29,31-32,53-76,89-123`
- 实际执行时，适配器的 cwd 是 workspace.path，prompt 是派发结果或用户发来的会话消息。Agent 可通过本地 CLI 在该目录读代码和文件；服务端没有将工作目录文件自动索引后注入 prompt 的路径。`apps/server/src/services/sessionManager.ts:315-342`
- `kb claim` 返回 issue 字段、工作空间路径和全部评论；`kb show` 返回 issue 与评论，消费接口标出新增评论。skill 要求 agent 开工和关键节点重新执行 `kb show`。`packages/cli/src/commands/claim.ts:7-25`、`packages/cli/src/commands/show.ts:15-35`、`apps/server/src/services/comments.ts:71-90`、`skills/agentboard/SKILL.md:42-54`
- 评论只有在 author 为 user 且 issue 同时有占用者和绑定 session 时会触发唤醒；无绑定 session 的 CLI claim 评论由后续 show 消费。`apps/server/src/services/comments.ts:31-62`、`apps/server/src/services/claim.ts:13-17`

## 权限与共享路径

- 设计文档的使用假设为单机单用户、Windows 优先。`Docs/设计文档.md:18`
- 服务监听 `127.0.0.1`；Express 装配 JSON 解析、API 路由、静态文件和错误处理中间件，未见登录、认证或角色授权中间件。`apps/server/src/index.ts:64-84,113-119`
- `KB_AGENT` / `agent_id` 用于记录 CLI 声明的身份；其值是 CLI 环境变量或 HTTP 请求体字段。`packages/cli/src/index.ts:34-41,74-87`、`apps/server/src/api/routes.ts:285-305`
- claim 为任务占用并发控制。done/fail 检查 issue 当前是否被占用，没有将调用者 agent_id 与 claimed_by 比对；release API 也没有调用者身份参数。`apps/server/src/services/claim.ts:35-58,63-89`、`apps/server/src/api/routes.ts:310-329`
- Web 与 CLI 共用同一数据库/API；没有用户、团队、角色、知识库 ACL 或跨设备同步模型。`apps/server/src/index.ts:64-67,113-119`、`apps/server/src/db/schema.ts:4-29`、`apps/server/src/api/routes.ts:169-418`
- CLI 可通过 `--server` 或 `KB_SERVER` 配置服务 URL，但项目内置服务本身仅监听本机回环地址。`packages/cli/src/index.ts:47-53`、`apps/server/src/index.ts:113-119`
- workspace.path 是本机文件夹路径；创建时只检查它存在且是目录，Agent 子进程以该路径为 cwd。文件可见性依赖运行该服务/子进程的操作系统账户文件权限。`apps/server/src/api/routes.ts:178-190`、`apps/server/src/services/sessionManager.ts:315-342`
