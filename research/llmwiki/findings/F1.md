### [7] Wiki 写入限定 Markdown 路径并串行验证持久化

- quote: "Create-only by default."
- url: [MCP path/content validation](https://github.com/nashsu/llm_wiki/blob/e08cfce65aad8b76b13546a081c1a8d4422b70c3/mcp-server/src/index.ts#L381-L403)；[Rust wiki writer](https://github.com/nashsu/llm_wiki/blob/e08cfce65aad8b76b13546a081c1a8d4422b70c3/src-tauri/src/agent/tools.rs#L650-L725)；[API write route](https://github.com/nashsu/llm_wiki/blob/e08cfce65aad8b76b13546a081c1a8d4422b70c3/src-tauri/src/api_server.rs#L1728-L1765)
- source_type: code
- published: 2026-10-22（固定发布提交）
- confidence: high
- 交叉验证: MCP 输入校验、API route、Rust writer
- 口径说明: 只允许规范化的 `wiki/*.md` 相对路径；正文上限 2 MiB；默认不覆盖已存在文件，需显式 `allow_overwrite=true`。Rust writer 持有进程级 `WIKI_WRITE_LOCK`，原子替换并逐字节回读验证，失败时尝试回滚。MCP 写入参数没有 revision / compare-and-swap 字段；因此同一路径并发且都允许覆盖时，序列中后一次成功写入会替代前次内容（由源码推断）。
