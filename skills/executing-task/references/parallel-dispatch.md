# 并行与滚动续派

## 准入

- 最多 3 路，含父会话。
- 每张卡列出目标 / 禁止文件；两两求交。
- 同文件或目录前缀重叠 → 串行。
- 同一工作区也允许多路，只要文件集不相交且 owner 不冲突。
- 跨工作区逐区取得授权。

## 父代理续派

worker 回合结束后，父代理立即：

1. `kb show` 回读当前卡状态、占用、决策锁。
2. 进行中且同一 owner：继续该卡。
3. 进行中但无 owner：重新核依赖与文件 owner，再 claim。
4. 待验收 / 已关闭：当前卡完成，进入续派。
5. 待规划：失败或释放后仍未完成；不自动重试。
6. 待决策：走 `ask-user`，不 claim 后继。
7. `kb next --json` 取可派卡，结合 `kb dep ls` 与在飞文件集选一张。
8. 把完整 UUID、工作区、卡范围、验收标准发给同一 worker。

## 依赖优先

- 已完成卡的已就绪下游优先。
- 下游仍被其他 blocker 挡住时，优先推进当前可 claim 的前置。
- 候选都不合格时，让 worker 空闲，不扩大授权。

## worker 输出

只回：

- 卡号；
- 结果；
- 提交短 hash；
- 一句话阻塞。

禁止贴完整测试日志、整段 diff 或大段命令输出。
