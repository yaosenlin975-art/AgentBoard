# Unslop 方向（AgentBoard 前端）

按 unslop（Damir Sokolovsky，CC BY 4.0）流程：先定方向，再九道 pass。

## 五条方向

- **Product**：本地任务看板，给「一个人 + 多个 AI agent」协作时看任务流转与交接。
- **Character**：`克制、精确、有值班台的味道`（calm, exact, a little industrial）。不用 clean / modern / sleek / premium 这类空词。
- **World**：值班台与控制面板——深色台面、金属刻度、贴纸式任务卡、琥珀色信号灯。中性色取**偏暖的石墨**（不是纯灰 #161616），强调色取**琥珀**（信号灯），主行动按钮用台面上「亮起的实体键」——浅底深字或深底浅字，而不是彩色实心大按钮。
- **Moments**（只两处，其余安静）：
  1. **看板卡片本身**：状态左侧细轨 + 依赖/截止的信号点，像贴在台面上的纸卡；这是产品的「实物」。
  2. **知识星图**：全站唯一允许丰富颜色的地方（节点按四类内容着色），因为它是「知识关系」的可视化，颜色在这里有意义。
- **Signature**：**卡片左侧 3px 状态轨 + 依赖锁标**，全站一致；出现在卡片和任务树行，不出现在别处。

## 九道 pass 的执行口径（本项目）

1. **Spacing**：一切落 4px 网格；同列卡片同高同间距；侧栏/顶栏行高 32–36；页面边距 24–32；清掉 `mt-[13px]` 这类一次性值。
2. **Color**：一套偏暖石墨中性 ramp（bg / raised / border / 三级文字），chrome 里**只有琥珀一个强调色**，用于主行动、选中态、以及「等 N 项」这类真正需要注意的数字；禁 hue 渐变、渐变文字、彩色光晕、彩色阴影、色块背景；边框是 6–10% 透明度的发丝线；暗色主题的层次靠 surface step + 发丝线，不靠阴影。
3. **Icons**：现有 emoji 全部换成 **lucide** 线性图标（项目已决定不引依赖？——**用项目已有的内联 SVG 或字符体系**，禁止新增依赖；若确需图标集，先报我）。统一 16px、1.5 stroke、取次级文字色、图标盒等宽。
4. **Copy**：中文短句；无感叹号；标题不写「欢迎回来」这类问候；标签用名词（「搜索」不写「搜索任何内容…」）；数字统一格式与 `tabular-nums`；不确定的宣称一律删。
5. **Type**：一套界面字体（沿用项目现有字体栈，不擅自换）；字号走少量档位；权重只用 400/500，600 仅极少数；层级靠字号与颜色，不靠字重；小字不得负字距；不用斜体强调；标签用中文句首大写语义（不用 `NAVIGATION` 式大写+宽字距）。
6. **Layout**：应用壳铺满视口，内容区上限 ~1600；看板列宽自适应（已完成）；侧栏 240–280；不做「窄居中列」。
7. **Details**：嵌套圆角相加（内 = 外 − 间距，≥4）；控件 8–10、卡片 12–16、面板 14–20；不是所有东西都是胶囊；计数与元信息用弱化 mono 文本而不是发光胶囊；键盘快捷键用 keycap。
8. **Visuals**：去掉装饰性渐变/光斑/发光网格；看板与知识页的 moment 来自产品自身（卡片实体感、星图）；不引入生成的图片。
9. **Motion**：删无意义循环动画（`animate-pulse` 用非实时状态处）、删 `transition-all` 与 `hover:scale`；只动 color/background/border/opacity/transform 并具名；一套缓动、少量时长；加载入场最多一次短淡入上移。

## 约束

- **不新增前端依赖**（图标用内联 SVG 或项目既有体系；真要引 lucide 先报我）。
- 产物增量超 40KB（min）先报我实测数字。
- 改动必须走测试页 5174 真机验证；完成后由我统一 `pnpm publish:web` 构建正式页。
- 保持功能与信息架构不变，只改视觉与文案。
