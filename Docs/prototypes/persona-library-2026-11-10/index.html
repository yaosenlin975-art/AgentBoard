智能体人设 全局库 · 即时生效

人设是全局资源（落中心库）。这里管理「库里有什么」；某个会话用哪个人设，仍到 聊天 → ⋯ → 会话设置 → 人设 里选，新建会话弹窗也读同一份列表。

还没有人设

新建一条人设，或从 WorkBuddy 专家包整包导入。不设人设的会话照常可用。

新建人设

内置人设由程序包提供，只读。需要定制请「新建人设」复制一份再改。

名称不能为空（上限 100 字）

人设正文不能为空

正文会作为系统提示词注入使用该人设的会话；工具与技能开关仍在会话设置里单独配置，不在这里。

删除人设？

删除后不可恢复。

会话与团队只保存 persona_id，没有外键约束；引用它的会话会显示「未知人设」，下一轮起不再注入该人设， 但会话本身仍可正常启动。

当前没有引用计数接口（会话分散在各工作区库），所以这里不做「有引用禁止删除」，只做明确告知。

从 WorkBuddy 专家包导入

整包导入：包内每个专家各生成一条人设（来源标记「导入」）；包内带 teamInfo 时，同时生成一个团队模板。

绝对路径优先；相对路径按服务进程 cwd 解析。

团队模板挂在该工作区；人设本身是全局资源。

评审说明 · 关键取舍

非产品 UI

PERSONA-LIB-1 · 页面内说明与 DESIGN-NOTES.md 同口径

  1. 入口：设置页单开一节，不加侧栏导航。人设是低频全局配置，与「工作区状态 / 语音 / 存储」同级。
  2. 职责边界：本节只管全局库；会话用哪个人设仍在「会话设置 → 人设」绑定，新建会话弹窗读同一份 GET /api/personas。
  3. 来源三态：builtin 只读（服务端 409，界面提前禁用）；import 与 user 可改可删，导入项额外显示包目录。
  4. 删除：只告知不阻断。session.persona_id 无外键、会话分散在各工作区库、暂无引用计数接口；删后会话显示「未知人设」，下一轮不再注入，但可正常启动。
  5. 导入：整包导入（后端按包事务写入），不做包内多选；同目录 / 同名重复导入按 409 原样展示服务端文案。
  6. 空态：给出「新建 / 从专家包导入」两条主行动，并说明不设人设的会话照常可用。
  7. 刻意不做：搜索、分页、排序切换、批量操作、引用计数——人设数量少，先把列表 + 增删改跑顺。

落地建议（写进 PERSONA-LIB-2）：新增 settings/PersonaSection.tsx 插入 SettingsDialog； 复用 queryKey ['personas']，写操作后 invalidate，保证会话设置下拉同步； 不改 apps/server。
