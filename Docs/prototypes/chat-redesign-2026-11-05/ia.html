五块能力入口

① 计划条：轮次顶部 ② diff 卡：工具结果内 ③ 三档确认：危险工具弹窗 ④ 阻塞态：轮次内提问卡 ⑤ 侧栏：搜索/重命名/归档/分叉

轮次状态机

idle→ 发送 → running→ 提问 → awaiting_input → 回答（同一轮）→running
running→ 危险工具 → awaiting_approval→ 允许 → running/ 拒绝 →stopped
running→ done| failed(step)→ 重试此步 → running(step)→done

三档确认作用域

  • 仅本次：只批准该次调用，不写规则
  • 本任务：规则绑定 issue_id，任务结束失效
  • 本工作区：规则绑定 workspace_id，跨会话生效；需撤销入口 + 审计

服务端落点

  • session：title / archived_at / 分叉来源
  • session_turn：state + plan_json + usage
  • message：turn_id / step_id / meta_json
  • approval_rule：scope + tool + 归属
  • 端点与 WS 事件见 DESIGN-NOTES
