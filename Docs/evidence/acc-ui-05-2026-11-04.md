## 2. 最终结构（web-graph 接线参考）

- **徽标那一组**（`AccountCard.tsx` 127-152 行区间）：`.accounts-client-current-*` / `.accounts-checkin-current-*` 仍是**两个并列 `<span data-testid>`**，内部由 `<Badge>` 改为 `<span className="rounded-md …">`：
  - 客户端当前 = `bg-accent-soft text-accent`（唯一强调色）；客户端非当前 = `text-ink-2`；未知 = `text-ink-3`
  - 签到当前 = `border-hairline text-ink`；不参与签到 = `text-ink-3`
  - 区域 / 签到能力不再用 Badge，降为 `text-ink-3` 文本
  - `已停用（只读）` = `text-accent font-medium`
  - → web-graph 接线「蓝灰标互斥 + 启停按钮」时，只需替换这两个 span 的内部实现，**外层 testid 与顺序未变**。
- **按钮那一排**（`AccountCard.tsx` 161-197 行区间）：顺序仍是 `切换为客户端登录账号` → `签到` →（可选 `已停用` 标记）→ `删除`；类名走 `BTN_BASE`/`BTN_QUIET`/`BTN_DANGER`（`rounded-lg`=8px 控件档）。启停按钮可以插在 `签到` 之后、`删除` 之前，不破坏这一排的 gap。

## 3. 令牌一致性

`BTN_BASE/BTN_QUIET/BTN_DANGER` 只组合 unslop 令牌与既有语义红：

```
BTN_BASE   : border-transparent + ab-transition + disabled 语义
BTN_QUIET  : border-hairline bg-surface-card text-ink hover:bg-surface-raised
BTN_DANGER : border-hairline bg-surface-card text-red-600 dark:text-red-400
强调主按钮  : bg-accent text-accent-ink hover:opacity-90
```

**没有新增任何色值字面量**（无 `#hex`、无 `rgb()`）。
