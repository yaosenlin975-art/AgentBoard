# 导航重构：左侧纵向栏 + 聊天整屏视图（2026-11-04）

状态：设计稿。原型经用户三轮走查确认（`.superpowers/brainstorm/win-20261104/content/nav-proto.html`，服务器 http://localhost:65220 可复看）。标注「（拍板）」的条目是我的决策，用户过目时可推翻。

## 1. 意图与背景

痛点：现状是「顶栏 + 各面板头部内嵌视图按钮 + 右侧浮窗」三层混合——视图入口散在 TopBar 与各面板头部（TOPBAR-INLINE），聊天挤在 320–720px 的右侧浮窗里，会话切换藏在顶部下拉，会话列表不可见；账号管理/设置各占一个 Modal 弹窗。

用户诉求（原话归纳）：
1. 「平铺看板 / 任务树 / 知识库 / 日志 / 聊天」做成左侧纵向栏；
2. tags 部分大致不变；
3. 聊天窗做成整屏界面：左会话列表 + 右消息与输入；
4. 顶栏不要了；账号、设置纵向排到左栏底部，从弹窗改为在右侧显示。

## 2. 目标 / 非目标 / 反目标

**目标**
- 左栏是唯一导航：五个视图入口互斥切换，聊天升为整屏视图；
- 顶栏整体移除；工作空间切换在左栏顶部，账号/设置在左栏底部、右侧滑出面板承载；
- tags+搜索行、新建任务入口（待规划列头 / 任务树工具条）保持现状不动。

**非目标**
- 看板 / 任务树 / 知识库 / 日志的内容重设计（只换入口与容器）；
- 聊天消息流内部重设计（复用现有消息渲染与发送逻辑，含语音输入）；
- 左栏折叠持久化、宽度拖拽、多工作空间并排；
- 任务详情浮窗改列（仍是浮窗）。

**反目标**（做成了也算失败）
- 左栏堆成第二信息区（只放：工作空间、五入口、账号/设置、状态小字行）；
- 界面出现第三种「窗口」形态（弹窗/浮窗/滑出面板三套并存）——弹窗类只剩任务详情/引用浮窗。

## 4. 视图状态模型（拍板）

- App 视图状态收敛为单一枚举 `view: 'board' | 'tree' | 'knowledge' | 'log' | 'chat'`，替代现有 `layout + knowledgeOpen + logOpen` 三态组合；互斥语义与现状等价。
- 聊天从 RightPanel 浮窗中移除，成为主区第五视图；RightPanel 只保留任务详情 / 引用浮窗（absolute 浮窗，行为不变）。
- 账号/设置滑出面板状态 `drawer: 'accounts' | 'settings' | null`，为主区 flex 兄弟（**挤压式**：打开时主区变窄，不遮内容）；两者互斥，✕ 或再点同一入口收起；无遮罩层。
- 重启遮罩（restart-blocker）、VoiceInputProvider、WS 事件订阅行为不变。

## 5. 聊天整屏视图（拍板）

- **左会话列表 250px**：顶部「+ 新建会话」；按「工作空间 / 无任务会话」分组（沿用现有分组口径）；条目 = 会话标题 + 最近消息摘要 + 未读红徽标 + 运行中橙点；数据源与现有 ChatPanel 顶部会话下拉相同（同一 sessions 接口），下拉控件删除。
- **右消息区**：头部（会话标题 · issue 号 · CLI/模型徽标）+ 消息流 + 输入栏（复用现有发送逻辑与长按语音麦克风按钮）。
- 进入聊天视图默认选中当前会话（无则最近一条）；切走再切回不重置选择。
- 左栏「聊天」入口徽标 = 全部会话未读合计，>99 显示 `99+`。

## 6. 账号 / 设置滑出面板（拍板）

- 宽度 400px（账号六行总览在 400px 放得下；展开层内容靠面板内滚动）。
- 账号面板内容 = AccountsPanel 本体，**六行总览设计不变**；`design-2026-11-04-accounts-unified-panel.md` §1「仍在弹窗内（Modal lg）」被本文档取代，其余条目（布局方案 C、§5–§10）全部继续有效。
- 设置面板内容 = 现有设置面板组件原样复用，只换容器。
- 面板打开时写操作禁用逻辑、能力矩阵失败禁用行为等随组件不变。

## 7. 左栏细节（拍板）

- 固定 176px，不可折叠、不持久化。
- 顶部工作空间切换：名称 ▾ + 路径小字；点击在按钮下方展开工作空间列表浮层（复用 TopBar 现有选择逻辑与数据）。
- 底部小字行：`● 服务运行中`（WS 状态，点击无操作）+ `浅色/深色`（点击切主题）。
- 窄屏（<768px）：左栏收为 56px 图标栏（隐藏文字标签与路径，保留徽标与状态点颜色）；替代现有 `md:hidden` 工作空间选择器行。
- 视觉沿用中性色 + 主题绿 + 细分割线体系；`prefers-reduced-motion` 下无动画（滑出面板用显隐切换，同现状浮窗做法）。

## 8. 约束

- 脱敏口径、数据接口全部不变；不新增后端端点。
- testid 迁移：TopBar 相关（工作空间选择器、聊天按钮、账号入口、设置入口）与聊天浮窗、账号 Modal 的既有 testid 需映射到新结构（左栏入口 / 聊天视图 / 滑出面板），映射写进任务说明；`main-content`、看板/知识库/日志内部 testid 不动。
- 既有测试（TopBar / ChatPanel / RightPanel / 账号 Modal 相关）按新结构改写，验收基线沿用：允许 `knowledge.test.tsx` / `detail.test.tsx` 既有失败，判定须空闲重跑。
- 与账号面板改造卡（C1–C5）解耦：本设计只动容器与入口，AccountsPanel 内部实现仍由那五张卡负责；但账号 Modal→滑出面板的容器改动归本设计实施卡。

## 9. 方案

| 方案 | 描述 | 取舍 | 结论 |
|---|---|---|---|
| A 顶栏保留 + 左栏 | 双层导航并存 | 入口重复，正是现状之病 | 否（用户红框否决顶栏） |
| B 左栏 + 顶栏瘦身为工作空间条 | 顶栏只留工作空间/状态 | 仍留一条横向 chrome | 否 |
| **C 左栏全接管，顶栏移除** | 工作空间/账号/设置/状态全部收进左栏；账号/设置右滑出 | 顶栏 testid 全迁移；账号 Modal 换容器 | **用户确认（原型三轮走查）** |

## 10. 验收

- web 测试无新增失败（基线口径见 §8）；新增用例：五视图互斥切换、聊天视图会话列表渲染与选中、滑出面板开合互斥与挤压、窄屏图标栏、左栏未读徽标聚合（含 99+）、主题切换入口。
- 变异测试至少 1 条 RED（视图互斥或徽标聚合口径）。
- `pnpm -r build` exit 0。
- CDP 走查测试页（5174）：默认态、五视图逐一点切、聊天双栏（含未读/运行点）、账号滑出与主区挤压、窄屏 375 图标栏、`prefers-reduced-motion` 无动画。
